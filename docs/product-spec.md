# Qpets 0.1.2 产品规格

## 产品边界

Qpets 是单机、Windows 优先的桌面宠物。首版不包含账号、云同步、在线商店、AI 对话、养成经济、Live2D、自动更新或跨平台发行。

## 角色

| ID | 名称 | 渲染器 | 来源 | 删除 |
| --- | --- | --- | --- | --- |
| `qpet-z1-sunny-brim` | 晴檐 | `sprite-atlas-v2` | 内置、默认 | 否 |
| `qpet-z2-violet-whisper` | 堇语 | `sprite-atlas-v2` | 内置 | 否 |
| `qpet-gu-candied-haw` | 糖葫芦 | `sprite-atlas-v2` | 内置 | 否 |
| `user.*` | 用户角色 | 任一受支持渲染器 | 用户导入 | 是 |

## 互动

- 单击轮换问候、观察和偶发跳跃动作。
- 拖动阈值为 6 像素，按方向播放左右移动动作。
- 滚轮按 5% 调整尺寸，范围 60%–160%。
- 指针离角色中心 54 像素外时，动态角色使用 16 方向帧；静态角色做轻微平移与倾斜。
- 闲置表演间隔可在 20–60 秒调整。
- 右键打开设置；托盘可打开设置、显示/隐藏桌宠、退出。

## 数据与失败回退

- Rust 是设置和角色库的唯一写入者。
- 内置资源只读，用户包位于应用数据目录的 `pets/packages`。
- 名称和介绍以本地覆盖层保存在 `state.json`，适用于内置与自定义角色；恢复默认时不改写角色包。
- 导入先进入 `.staging`，通过路径、清单和像素校验后才移动到正式目录。
- 删除先移动到 `.trash`；状态保存失败时恢复原目录。
- 当前角色缺失、损坏或被删除时回退到晴檐。
- 角色包不允许脚本、符号链接、嵌套路径、未知运行时文件或保留 ID。

## 验收

- 首次启动展示晴檐。
- 三个内置角色都能切换并在重启后保持选择。
- 动态角色动作和 16 方向注视遵循 v2 图集契约。
- 静态角色能完成待机、点击、拖动、跳跃和注视的通用动画。
- 自定义透明图片和完整角色包可安全导入、选择与删除。
- 所有角色的名称和介绍都可编辑、持久化并恢复角色包默认值，长文字不会撑破设置界面。
- 设置即时同步到两个窗口并持久化。
- CI 在 Windows 上通过 Rust 测试并构建 NSIS 安装包。
